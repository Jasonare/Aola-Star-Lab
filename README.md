# Aola-Star-Lab

奥拉星怀旧资源整合网站，用来整合奥拉星怀旧游戏版本、攻略、文案等。项目使用 Spring Boot、Thymeleaf 和 JPA。

## 构建与启动

需要 JDK 17 或更高版本，以及 Maven 3.6.3 或更高版本。项目没有 Maven Wrapper；请先安装 Maven，并确保 `JAVA_HOME` 指向 JDK。以下命令在项目根目录的 Windows PowerShell 中执行：

```powershell
java -version
mvn -version # 确认 Maven 使用的 Java 也是 17 或更高版本
mvn test
mvn package
```

首次启动时，应用会自动确保固定内置管理员账号存在，不依赖 `ADMIN_USERNAME` 或 `ADMIN_PASSWORD` 环境变量：

- 管理员用户名：`aolaAdmin`
- 管理员密码：`aolaResource`
- 管理员验证码：`5aWl5ouJ5pif5oCA5pen6LWE5rqQ5pW05ZCI`

管理员登录必须同时提交用户名、密码和验证码；普通用户登录不要求验证码。密码只以 BCrypt 哈希形式保存。公开注册始终创建普通用户，不能创建或占用 `aolaAdmin`。以上是用户指定的固定弱凭据，仅适合当前约定场景，生产环境应尽快替换为更强且可轮换的认证方案。

默认监听端口为 8080，可运行 `mvn spring-boot:run` 或：

```powershell
java -jar .\target\aola-star-lab-1.0.0.jar
```

### 用户与密码规则

- 普通注册用户名为 3–40 位英文字母、数字或下划线；密码至少 8 个字符（Java 字符串长度），UTF-8 编码不超过 72 字节。
- 管理员账号由应用首次启动自动引导创建；如果固定用户名已被普通用户占用，应用启动会失败。

## 数据库与上传配置

应用使用 MySQL 8.0，主配置位于 `src/main/resources/application.yml`。默认服务器及账号与本机 `D:\Mind-Hub-main` 项目一致，数据库名为 `aola_lab`。数据库密码保存在本机 `config/mysql-local.yml`，该文件已被 Git 忽略，不应提交到版本库。相对路径以启动进程的工作目录为准，建议从项目根目录启动；在其他机器运行时，需自行提供同名本地配置文件或设置环境变量。

首次使用前，确认连接的是目标 MySQL 服务器，并用有建库、建表权限的账号执行 [sql/aola_lab.sql](sql/aola_lab.sql)。例如，在已登录的 MySQL 客户端中：

```sql
source D:/Aola-Star-Lab-main/sql/aola_lab.sql;
```

脚本使用 `utf8mb4`，创建 `aola_lab` 和九张表；不会删除现有数据库或表，表已存在时会报错停止而不做兼容性检查。执行前请备份并核对目标库，切勿直接用于已有数据的迁移。管理员账号不包含在 DDL 中，首次启动应用时由应用自动创建。

可使用 `DB_URL`、`DB_USERNAME` 和 `DB_PASSWORD` 环境变量覆盖连接参数。MySQL 驱动已包含在项目依赖中；测试使用独立的 H2 内存数据库，不连接远程 MySQL。切换数据库不会自动迁移旧数据，请单独备份数据库及上传目录。

**表结构注意：**默认 `DB_DDL_AUTO=update` 会让 Hibernate 创建或修改表结构。手工执行初始化脚本后，建议设置 `DB_DDL_AUTO=validate` 以校验结构且不自动更改；已有数据库应先备份并核对。

上传文件默认保存在工作目录下的 `./data/uploads`，可通过 `APP_STORAGE` 环境变量指定其他目录。腾讯云 COS 配置从 `./data/uploads/cos.yml` 加载；该文件已加入 Git 忽略规则，不应提交或复制到公开位置。配置项包括 `app.cos.enabled`、`bucket`、`region`、`secret-id` 和 `secret-key`。启用 COS 时必须提供有效凭据，否则应用启动失败；图片、视频和资源对象存入 COS，使用随机对象键，不生成公开对象直链。应用先执行内容/资源可见性校验，再由服务端 SDK 读取对象，因此 COS 桶应保持私有，并给子账号授予目标桶所需的最小上传、读取、删除权限。不要把密钥写入跟踪文件或日志；密钥若曾在聊天、代码提交或其他不受控位置暴露，应立即在腾讯云轮换。未启用 COS 时文件保存在本地，并通过经过权限检查的应用接口读取。单文件限制为 100 MB，整个 multipart 请求限制为 105 MB。

## 主要功能

- 用户注册、登录、最近登录记录；好友申请及接受。
- 发布、编辑博客或视频，选择公开、仅好友或仅自己可见；支持标签、搜索和筛选。博客可附一张 PNG、JPEG 或 WebP 图片，视频为 MP4；编辑后需重新审核。
- 管理员审核内容、管理标签和资源目录，上传资源并控制其可见性。资源支持 PNG、JPEG、WebP、MP4、PDF、ZIP、EXE 和 APK。
- 已审核博客可评论；个人页面展示内容数量、最近评论和登录记录。

## 局限

- 登录后才能访问内容和资源；公开内容指对有权限的已登录用户可见，并非匿名公开。资源是否可见由管理员控制。
- 文件类型校验依赖扩展名和文件头签名（EXE 为 MZ，APK 为 ZIP 签名），不验证安装包结构、有效性或安全性，也不进行恶意内容扫描；生产部署还需独立的安全检查、访问控制、备份和容量管理。
- 替换博客图片或视频后，旧文件目前不会自动清理，可能长期占用磁盘。由于并发更新和文件引用等问题，不能直接按旧记录删除；请在核对数据库引用、备份并停止相关写入后，由管理员谨慎清理孤儿文件。
- 自动更新表结构适合开发环境；生产环境应自行规划数据库迁移、凭据保护和备份恢复。
